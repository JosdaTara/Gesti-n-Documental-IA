# 1. Descripción del entorno de desarrollo

- **Lenguajes:**
  - Backend: Python 3.11
  - Frontend: TypeScript 5 (sobre React 18)
  - Scripts BD: SQL (PostgreSQL 16)
- **Frameworks:**
  - Backend: FastAPI, SQLAlchemy, Pydantic
  - Frontend: React 18 + Vite, React Router, Axios, Chart.js
  - IA: openai (embeddings/LLM), PaddleOCR, pytesseract, PyMuPDF, pdfplumber, python-docx
- **IDE/herramientas:**
  - VS Code con extensiones para Python (Pylance) y TypeScript/React
  - Docker Desktop (para el despliegue con Compose)
  - pgAdmin o DBeaver para administración de PostgreSQL
  - Insomnia/Postman o Swagger (`/docs`) para probar la API
- **Control de versiones:** Git

  - Repositorio: `https://github.com/JosdaTara/Gesti-n-Documental-IA.git` (ver folder `09-Codigo-Fuente`)
  - Rama principal: `main`
  - Flujo: commits por módulo/entregable, mensajes descriptivos en español.
