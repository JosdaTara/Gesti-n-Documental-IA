# 12. Video Demostración

Video funcional de SIGAD utilizado en la sustentación final.

## Archivo principal

| Archivo | Descripción |
|---|---|
| `SIGAD-Demostracion.mp4` | **Pendiente de grabar** siguiendo el guion `Guion-Demostracion.md`. Reemplazar esta celda con el nombre real del archivo una vez grabado. |

## Cómo grabar

1. Asegurarse de que el proyecto esté corriendo:
   - Backend: `http://127.0.0.1:8000`
   - Frontend: `http://localhost:5173`
2. Tener una sesión de admin iniciada y la base de datos con documentos de prueba
   (ver carpeta `11-Repositorio-Documentos-Prueba`).
3. Grabar con **OBS Studio** o **Win+G** (Full HD, 25-30 fps, micrófono activo).
4. Seguir el guion de `Guion-Demostracion.md` (8 módulos, ~7 minutos).

## Requisitos del entregable

- Formato: `.mp4` (H.264), resolución mínima **1280×720**, ideal 1920×1080.
- Duración recomendada: 6–8 minutos.
- Incluir narración explicativa en español.
- Subir el archivo a esta carpeta y/o publicarlo en YouTube; anotar el enlace aquí:

## Estructura del guion (rápida)

1. Presentación del proyecto.
2. Acceso seguro (login).
3. Tablero de control.
4. Carga y clasificación automática con IA.
5. Búsqueda semántica.
6. Asistente documental con RAG (respuestas con fuentes).
7. Administración (nueva categoría, usuarios, auditoría).
8. Cierre.
